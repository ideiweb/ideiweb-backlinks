## Elegant Background Animation with Pure CSS

This snippet creates a smooth, subtle background movement effect using a pseudo-element and CSS keyframes. It's ideal for hero sections, feature cards, or any container that needs a touch of life without distracting from the main content.

```css
selector {
  position: relative;
  overflow: hidden;
}

selector::before {
  content: "";
  position: absolute;
  top: 0; left: 0;
  width: 100%;
  height: 100%;
  background-image: url(https://codeponents.com/wp-content/uploads/2025/04/Looper-BG.png);
  background-repeat: no-repeat;
  z-index: 0;
  transform-origin: center;
  animation: elegantMove 6s ease-in-out infinite;
}

selector > * {
  position: relative;
  z-index: 1;
}

@keyframes elegantMove {
  0% {
    transform: translate(0px, 0px);
  }
  25% {
    transform: translate(10px, 5px);
  }
  50% {
    transform: translate(5px, 10px);
  }
  75% {
    transform: translate(-10px, -5px);
  }
  100% {
    transform: translate(0px, 0px);
  }
}
```

```css

  width: max-content;

}

  border-radius: 24px;

.infinite-item img {
  height: 40px;
  width: auto;
}

  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(-50%);
  }
}
```
